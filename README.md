## 概要

本リポジトリは、大地震発生時に素早く状況を確認・対応するための簡易ツールやチェックリストをまとめた資料群です。主に静的な HTML やドキュメントで構成され、日常的に常用デバイスへ保存しておくことで有用となる内容を中心としています。

---

## 主な内容

- 大地震発生時チェッカー（docs/）
  - 簡易な HTML ファイル群で構成されたダッシュボード（PWA 対応）。地震情報、接続診断、停電情報などへのリンク集です。
  - ダッシュボード（Web）：https://watanabe3tipapa.github.io/4eq-2025-12-08/

- その他ドキュメント（items/）
  - 確認しておくこと・準備しておくこと・覚えておくこと（./items/paper.md）
  - 家庭用72時間キット（./items/72hr-kit.md）
  - Yahoo! 主要防災サービス（./items/yahoo.md）

---

## 開始・利用方法

- 大地震発生時には、スマートフォンなどに保存したダッシュボードや該当ドキュメントを参照して各チェックを実行してください。
- 状況の変化を確実に把握するため、30分単位での再確認を推奨します。

注：リポジトリ内の大地震発生時チェッカーは簡易な静的 HTML で構成されています。ローカルに保存しておくとオフライン時にも参照しやすくなります。
